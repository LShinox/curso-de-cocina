# Curso de cocina desde cero

App web (PWA) con un curso de cocina de 10 semanas: sesiones con ingredientes y pasos, modo cocinando, listas de compras por plan y notas de seguridad. Está en español y pensada para el celular.

Funciona sin conexión una vez cargada. Todo lo que marcas (progreso, ajustes, compras) se guarda solo en tu dispositivo, en el almacenamiento del navegador; no hay cuentas ni servidor, y nada se envía a ningún sitio.

Para instalarla en el celular: en Chrome, menú ⋮ y "Instalar app" (o "Agregar a pantalla principal").
